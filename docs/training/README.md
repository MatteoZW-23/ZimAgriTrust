# Training Materials

This directory contains training materials for users, agents, and developers.

## Contents

- `AGENT_TRAINING_MANUAL.md` - Training manual for field agents
- `Platform_Walkthroughs.md` - Platform walkthrough guides
- `User_and_Agent_Manual.md` - User and agent manual
- `WHATSAPP_ENHANCED_GUIDE.md` - WhatsApp integration guide

## Audience

- **Field Agents**: Use AGENT_TRAINING_MANUAL.md
- **End Users**: Refer to User_and_Agent_Manual.md
- **Developers**: Check WhatsApp integration guide for bot features

## Training Flow

1. Start with platform walkthroughs
2. Review role-specific manuals
3. Practice with simulator tools
4. Reference integration guides as needed
