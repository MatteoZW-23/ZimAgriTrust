## Architecture Overview

The ZimAgritrust platform consists of:
- Backend API (FastAPI/Python)
- Frontend applications (React)
- Mobile applications
- IoT gateway services
- WhatsApp integration
- USSD services

## Components

- **Backend**: Core API and business logic
- **Database**: PostgreSQL with Redis caching
- **ML Services**: Machine learning models for crop detection
- **Integrations**: WhatsApp, USSD, IoT gateways
